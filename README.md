# Mimzi media

Videos, captions and thumbnails for the **Mimzi – Little Learners, Big Dreams** YouTube channel (toddler learning, ages 1–3), published through Sonap.

- `videos/` – finished MP4s and matching `.srt` caption files
- `thumbnails/` – 1280x720 YouTube thumbnails
- `pipeline/` – render code (`mzart.py` = Mimzi, Teddy, picture cards, backgrounds) and episode scripts
